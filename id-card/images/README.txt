## Image Requirements:

- Recommended size: 300x200px (3:2 aspect ratio)
- Max file size: 500KB per image for fast loading
- Use descriptive alt text in HTML for accessibility

## Tips:
- Use high-quality photos that showcase your work clearly
- Ensure good lighting and sharp focus
- Consider using a consistent background or style
- Optimize images for web (compress if needed)
